Your AI chat tabs, working as one crew

tabcrew is a Claude Code skill. It writes to the DeepSeek, ChatGPT and Gemini chats you already have open in Chrome, passes the right parts between them, and does the work in your repo.

> Install the skill from https://github.com/fatih255/tabcrew

Paste it into Claude Code. Needs the open-source tabcrew Chrome Agent Chrome extension (included).

Read the docs on GitHub →Free and open source (MIT) · No API keys

See what the agent does

tabcrew drives Chrome through tabcrew Chrome Agent, an open-source extension that ships with the skill. It runs on your computer only: no account, no server, no analytics.

A cursor and a caption

While the agent works in a tab, a black cursor shows where it points and clicks, with a short caption of what it is doing. The tab title shows ⏳ while it works and ✅ when it is done.

Follow one agent

The popup lists the agent tabs per agent, for example Claude Code · my-app. Click the eye and the window shows the tab that agent is working in. Other agents never move the view.

Its own tab group

The agent only acts in tabs inside its grey “tabcrew” group, never in yours. Block sites, or make it ask before it acts on a new one.

Several profiles, any MCP client

Load it in each Chrome profile you use; tabcrew picks the one logged in to your chat. Codex CLI, Gemini CLI, Cursor and other MCP clients can use it too.

If you copy prompts from a chat into Claude Code and paste the results back, tabcrew does that loop for you.

The chats think

You keep the chats you already use. tabcrew opens its own tabs, writes the message, waits for the answer and reads it back, including long code blocks and tables.

A small helper agent for each chat picks out the part of the reply meant for Claude Code or for the other chat, in any language.

Claude Code does the work

Claude Code runs every step in your repo: edits files, runs tests, and reports the real result back to the chat, round after round.

Chat replies are treated as input for your goal, not as commands. Deleting, deploying, publishing and anything that touches secrets waits for you.

One chat, two, or three at once

Describe the job in plain words, or call /tabcrew with a workflow, the chats and a round limit.

Three workflows

Mix chats or repeat one: ChatGPT against Gemini, three DeepSeek tabs, two ChatGPT tabs plus a Gemini tab.

  • soloOne chat leads. Claude Code carries out each step and reports back.
  • debateTwo chats argue until both agree on one written conclusion, then Claude Code builds it.
  • fanoutEach chat researches its own subtopic at the same time. Claude Code checks the claims, merges and acts.

Your own sessions

Works through the open-source tabcrew Chrome Agent extension and the chats you are already logged in to. No API keys, no extra subscriptions.

Replies checked

Each reply comes back with its length and a hash. Missing code blocks, tables or a short read are flagged instead of passed on silently.

Long messages split

A message over a site's limit (ChatGPT about 10,000 characters, Gemini 32,000) goes out in ordered parts.

Site errors noticed

"Too many requests", lost connections and silent stalls are caught. The tab is reloaded and the message tried once more.

Session memory

Every run leaves dated Markdown notes in .tabcrew/, so a later session can pick up where this one stopped.

Knows when to stop

A round limit of 5, 10 or 20, or "until done" with a check that pauses the run when it stops making progress.

Supported chats

Each chat site has its own adapter that writes, waits and reads in that site's page. You stay logged in with your own account.

chat.deepseek.com

DeepSeek

Supported

55k max characters in one message; longer messages are split into parts

  • DeepThink and Search can be turned on per seat
  • Reloads the tab and retries when the site stalls
  • Notices “Check network and retry” and other site errors
chatgpt.com

ChatGPT

Supported

9.5k max characters in one message; longer messages are split into parts

  • Reads code from its collapsed code viewer in full
  • Notices “Too many requests” and other site errors
  • Saves the images it generates to a folder, with no download dialog
gemini.google.com

Gemini

Supported

32k max characters in one message; longer messages are split into parts

  • Asks Gemini to paste code it put in the Canvas panel
  • Notices error pop-ups and replies that never arrive
  • Saves the images it generates at full size, with no download dialog

Not yet Claude.ai, Grok, Perplexity and others. An adapter is three small scripts: status, send and read. Add one →

Why let the chats work together

No more copy and paste

The loop between a chat and your terminal runs by itself, and the chat sees real test output instead of your summary of it.

A second opinion built in

In a debate one chat checks the other. In fanout Claude Code checks each claim before acting.

Use what you already have

The chat accounts you already use stay useful, and Claude Code spends its effort on the repo work.

A record you can read

Goals, decisions, what changed and the next step are written down in plain files you can commit or ignore.

Questions

Which chats does it support?

DeepSeek, ChatGPT and Gemini. Claude.ai, Grok, Perplexity and others are not supported yet; adapters are welcome.

Does it need API keys?

No. It drives the chat websites in your own Chrome through the open-source tabcrew Chrome Agent extension, using the accounts you are logged in to.

Will it type into my open tabs?

No. It works only in tabs it opened itself. They stay open when it finishes, so you can read the whole conversation.

What does it store in my browser?

Nothing in the chat sites. The extension keeps only its own settings (the browser's name and your site permissions) and, until Chrome closes, which agent works in which of its tabs.

Can several agents use the browser at once?

Yes. Each works only in the tabs it opens, all in the same “tabcrew” group, and the popup shows which agent works where. You can follow one of them with the eye.

Does the extension work without tabcrew?

Yes. tabcrew Chrome Agent is a standalone MCP server for your real Chrome, for Claude Code, Codex CLI, Gemini CLI, Cursor, VS Code and other MCP clients.

What if a chat is logged out?

It asks you to log in. It never types passwords, and messages to the chats never include .env values, keys or tokens.
